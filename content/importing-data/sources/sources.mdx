# Data sources

## Open map data (AOI → project tables)

| Source | Studio | Worker job | Guide |
|--------|--------|------------|-------|
| [OpenStreetMap](https://www.openstreetmap.org/) | OSM Import Map | `osmImportArea` | [OpenStreetMap](./osm.mdx) |
| [Overture Maps](https://docs.overturemaps.org/guides/) | Overture Import Map | `overtureImportArea` | [Overture Maps](./overture.mdx) |

OSM and Overture are complementary: OSM is strong for roads/hydro and community mapping; Overture often has fuller building (and other) coverage for the same AOI.

## Files and desktop GIS

Shapefile, GeoJSON, GeoPackage, KML, etc. — import with [QGIS](../../guides/gis-analyst/importing-from-qgis.mdx) or [ogr2ogr](../formats/gis-formats.mdx).

## Advanced OSM extracts

For full `.osm.pbf` extracts and custom styles (e.g. 3D buildings), use [osm2pgsql](./osm2pgsql.mdx) against your project database connection string.
