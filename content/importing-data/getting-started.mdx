# Importing data into Geobase

Bring geospatial data into your **Geobase project** (PostGIS), then explore it in Table Editor and the Tile Server.

## Prefer Studio when you can

In Studio, open **Data Importer** for your project:

| Path | What it does |
|------|----------------|
| **Map imports → OSM Import Map** | Draw an AOI, pick OSM topics, run worker job `osmImportArea` |
| **Map imports → Overture Import Map** | Draw an AOI, pick Overture types, run worker job `overtureImportArea` |

You can cancel a pending/running map-import job from the sidebar. Stopping child processes (e.g. osm2pgsql) may still be best-effort depending on worker version.

Browse / URL / Upload / Live Sources are evolving; for file-based GIS formats, use QGIS or `ogr2ogr` below.

## Choose a path

| Source / format | Recommended | Also | Guide |
|-----------------|-------------|------|-------|
| OpenStreetMap (AOI) | Studio **OSM Import Map** | Worker API `osmImportArea` | [OpenStreetMap](./sources/osm.mdx) |
| Overture Maps (AOI) | Studio **Overture Import Map** | Worker API `overtureImportArea` | [Overture Maps](./sources/overture.mdx) |
| Large local `.osm.pbf` / custom Lua | `osm2pgsql` on your machine | — | [osm2pgsql (advanced)](./sources/osm2pgsql.mdx) |
| Shapefile, GeoJSON, GeoPackage, … | QGIS | `ogr2ogr` | [QGIS](../guides/gis-analyst/importing-from-qgis.mdx), [formats](./formats/gis-formats.mdx) |

## After import

1. Confirm tables in **Table Editor** (and `source` / provenance columns where applicable).
2. Expose layers in the **Tile Server** if you need MapLibre tiles.
3. For agent / CI automation, use the [worker jobs](/reference/worker-jobs) endpoints with a service role key (never from the browser).
