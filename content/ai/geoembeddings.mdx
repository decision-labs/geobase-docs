# GeoEmbeddings

Embeddings tables live in the project `geoembeddings` schema (catalogue + patch vectors). Use the right integration path for the job:

| Path | Use when | Docs |
| --- | --- | --- |
| **RPC** | Interactive similarity / change detection against Postgres | [RPC API](/guides/geoembeddings/rpc-api) |
| **Worker jobs** | Create embeddings from GeoTIFF or SRAI (async) | [Worker jobs](/reference/worker-jobs) · [SRAI pipeline](/guides/srai/automated_srai_pipeline) |
| **GeoParquet** | Bulk analytics on exported files in Storage | [Connect to GeoParquet](/ai/geoembeddings/geoparquet) |
